# Documents Activity Tracker

一个用于 Obsidian 的文档阅读时间追踪插件，帮助你了解在每个文档上花费的时间。

## 功能特性

### 核心功能
- **实时计时追踪**：自动追踪文档阅读时间
- **会话管理**：支持多轮阅读会话，每次打开文档开始新的一轮
- **暂停/继续**：手动控制计时状态
- **空闲检测**：自动检测用户活跃状态，空闲时暂停计时
- **窗口焦点检测**：窗口失焦时自动暂停计时

### 显示界面
- **嵌入式计时器**：在文档顶部显示实时计时信息
  - 会话开始时间
  - 当前轮次（今日第N轮）
  - 全库今日总时长
- **会话详情面板**：查看详细的时间轴记录
  - 活跃/暂停时段明细
  - 会话统计汇总
  - 保存状态标记

### 数据可视化
- **热力图视图**：按小时展示阅读活动热力图
- **文档列表**：查看所有文档的阅读记录
- **时间统计**：今日阅读时长、总阅读时长等

### 高级功能
- **文件过滤**：支持按路径/标签排除特定文件
- **最小会话时长**：设置最小保存阈值，过滤短暂浏览
- **多标签页支持**：正确处理多标签页场景
- **移动端适配**：支持移动设备使用

## 安装

1. 下载最新的 release 版本
2. 将 `main.js`、`styles.css` 和 `manifest.json` 复制到 `.obsidian/plugins/documents-activity-tracker/` 目录
3. 在 Obsidian 设置中启用插件

## 使用

### 基本操作
- **自动开始**：打开文档后自动开始计时（可在设置中调整）
- **暂停/继续**：点击计时器中的暂停按钮
- **保存会话**：点击保存按钮将当前会话保存到历史记录
- **弃用会话**：点击 X 按钮丢弃当前会话并开始新一轮

### 查看记录
- **命令面板**：
  - `Show all reading records` - 查看所有文档记录
  - `Show file reading records` - 查看当前文档记录
- **详情按钮**：点击计时器中的图表按钮查看会话详情

## 设置选项

- **自动开始模式**：控制打开文档时的行为
- **空闲超时**：设置多久不活跃后暂停计时
- **今日总时长显示**：选择何时显示全库今日总时长
- **最小会话时长**：过滤小于指定秒数的会话
- **文件过滤**：排除特定路径或标签的文件

## 技术特性

- **数据结构**：基于时间轴的会话记录系统
- **状态管理**：tracking（活跃）、pausing（暂停）、saved（已保存）
- **性能优化**：
  - 缓存优化，减少磁盘 I/O
  - 实时更新机制
  - 内存泄漏防护
